# Auto Service Website Template

A responsive HTML/CSS/JavaScript template for a small automotive repair/service business.

## Files
- index.html — complete single-page website
- css/style.css — responsive styling
- js/main.js — mobile navigation, FAQ accordion, demo appointment form

## Customize before launch
1. Replace "Iron Ridge Auto Service" with the real business name.
2. Replace phone number, address, hours, services, reviews, warranty, and other placeholder content.
3. Replace the shop photo placeholder with real business photography.
4. Replace the map placeholder with a Google Maps embed or another map provider.
5. Connect the appointment form to your preferred form/backend/email service.
6. Add the business's real Google Business Profile review link.
7. Add appropriate legal/privacy information for the actual business.
8. Add LocalBusiness structured data and final SEO metadata.

No framework is required; open index.html in a browser to preview it.
